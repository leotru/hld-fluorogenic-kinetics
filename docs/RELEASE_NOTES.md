# v1.0.0 — Initial research-software release

Initial citable version of the computational analysis of a fluorogenic
haloalkane dehalogenase assay, based on aggregate parameter values
reported by Mion et al. (2026), preprint DOI:
https://doi.org/10.64898/2026.10.02.756220

Included:
- Full mass-action reaction model with bound and covalent enzyme intermediates.
- Quasi-steady-state rate-law comparison and model invariant checks.
- Substrate-depletion calculations under specified assay conditions.
- Synthetic-noise parameter fitting and practical identifiability assessment.
- Reproducible numerical analysis scripts and reference tables/figure.
- MIT software license, citation metadata, tests, and automation.

Scientific scope: **the repository contains no original experimental dataset**;
simulations use reported aggregate parameters and synthetic noise.
Consult `docs/REPRODUCIBILITY.md` before generalizing the numerical findings.
